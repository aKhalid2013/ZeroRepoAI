# 00 Start Here

Use this repo as the starting point for a new project.

## Step-by-Step
1) Copy this repository to a new project location.
2) Read `docs/PRINCIPLES.md` and `docs/WORKFLOW.md`.
3) Fill in `docs/PRD.md` and decide whether to create a project charter.
4) Triage the first piece of work:
   - Chore: small change, low risk.
   - Feature: new behavior, medium/high risk.
5) For the first Feature:
   - Create a feature spec from `docs/FEATURES/_TEMPLATE.md` (use `scripts/new-feature.*`).
   - Set Status to "Questions Open" and let the Spec Agent close all questions.
6) Configure quality gates in `docs/QUALITY_GATES.md` (copy from template if needed).
7) Proceed with the Chore or Feature track in `docs/WORKFLOW.md`.
